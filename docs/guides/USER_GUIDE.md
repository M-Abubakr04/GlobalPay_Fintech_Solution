# User Guide

## Customer

1. Sign in with `customer@globalpay.example.com`.
2. Open **Customer & Wallet** to view the profile, masked identity data, balance and activity.
3. Open **Payments** and send a simulated transfer to `receiver@globalpay.example.com`.
4. Select **new device** to increase the risk signal and potentially generate a fraud alert.
5. Open **Open Banking / CBDC**, create a scoped consent and call the AIS endpoint.
6. Create a simulated ePKR wallet.

## Fraud analyst

1. Sign in with `analyst@globalpay.example.com`.
2. Open **Fraud Operations**.
3. Train the lightweight classifier.
4. Review alerts, inspect reasons and record a human decision.

## Executive

1. Sign in with `executive@globalpay.example.com`.
2. Open the Executive Dashboard.
3. Review customers, wallets, payment volume, alerts, API use and trends.
4. Export a simulated executive report.

All financial and identity records are synthetic demonstration data.
